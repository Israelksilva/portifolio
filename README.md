## 📂 Projetos em Destaque

### 🧮 [Calculadora Científica](https://github.com/Israelksilva/calculadora)
Calculadora web avançada com funções trigonométricas, logaritmos e constantes matemáticas. Focada em precisão e design responsivo.

### 🐍 [Snake Game Neon](https://github.com/Israelksilva/fliperama-de-cobra)
Um remake do clássico "jogo da cobrinha" com estética Dark/Neon, sistema de recordes local e animações fluidas.

### 🧩 [Jogo da Memória](https://github.com/Israelksilva/jogo-da-mem-ria)
Desafio interativo de memória que exercita a manipulação do DOM e lógica de estados em JavaScript puro.
